# 한국어·영어 STT 4개 비교

2026-10-28 측정. **14개 조건, 샘플 평가 140건 모두 성공.**

실시간 회의 자막은 **Amazon Transcribe**, 발화 구간을 모아 인식하는 SageMaker 경로는 **Qwen3-ASR**을 우선 추천한다. 이번 표본에서 Qwen은 한국어 전체 문장 정확도가 Transcribe와 같았고, 6초 분할에서도 다른 SageMaker 모델보다 오류가 적었다. 영어 전체 문장은 Qwen·Transcribe·Whisper가 비슷했다.

이 판단은 한국어 10개, 영어 10개의 낭독 음성에 한정한다. 실제 회의 전체나 모든 화자의 성능 순위로 일반화할 수 없다.

## 전체 문장

한국어는 문자 오류율(CER), 영어는 단어 오류율(WER)이다. 둘 다 낮을수록 좋지만 서로 다른 지표이므로 언어 사이에서 숫자를 직접 비교하지 않는다. 처리시간은 이미 녹음된 파일을 제출한 시점부터 최종 인식 결과까지의 중앙값이다.

| 엔진 | 한국어 CER | 영어 WER | 한국어 처리시간 | 영어 처리시간 |
|---|---:|---:|---:|---:|
| Qwen3-ASR 1.7B | **2.68%** | **3.32%** | **0.81초** | **0.53초** |
| Amazon Transcribe | **2.68%** | 3.79% | 2.99초 | 3.24초 |
| Whisper large-v3-turbo | 3.58% | 3.79% | 2.37초 | 2.08초 |
| Nemotron 3.5 ASR 0.6B | 9.84% | 9.48% | 3.58초 | 3.31초 |

영어 정답은 정규화 후 211단어다. Qwen의 단어 편집 오류는 7개, Transcribe·Whisper는 각각 8개로 **차이는 단 1개**다. 이 표본으로 세 모델의 영어 정확도에 확정적인 순위를 매기지는 않는다.

**처리시간은 실시간 자막 지연이 아니다.** Transcribe에도 파일을 실시간 속도로 기다리지 않고 전송했다. Transcribe·Whisper는 미국 동부, Qwen·Nemotron은 서울에서 호출했으며 하드웨어와 서빙 구현도 다르다. 위 시간은 이번 배포 구성의 관측값이지, 동일 조건에서 모델의 연산 속도만 비교한 결과가 아니다.

## 앱 기본값에 가까운 6초 분할

SageMaker 입력을 6초씩 독립 요청으로 보내고 인식 결과를 합쳤다.

| 엔진 | 한국어 CER | 영어 WER |
|---|---:|---:|
| Qwen3-ASR 1.7B | **5.82%** | **4.27%** |
| Whisper large-v3-turbo | 12.08% | 6.64% |
| Nemotron 3.5 ASR 0.6B | 15.66% | 13.74% |

Transcribe는 하나의 지속 스트리밍 세션을 유지하므로 별도의 6초 독립 요청 실험을 하지 않았다. 전체 문장 결과를 참고한다.

Qwen도 한국어 CER이 전체 문장 2.68%에서 분할 시 5.82%로 올라갔다. 모델 선택뿐 아니라 단어와 문맥을 끊지 않는 입력 방식이 중요하다. 앱의 6초 수집 시간은 위의 파일 처리시간에 포함되지 않는다.

이번 Whisper 요청에는 한국어 또는 영어를 명시했다. [이전 자동 감지 조건](../stt-comparison-2026-10-28/README.md)의 한국어 6초 분할 결과(15.44%)와 조건이 다르다.

## 선택 기준

- **발화 중 자막을 바로 보고 싶을 때:** Transcribe. 이번 비교에 사용한 앱 연결에서는 부분 결과를 지속적으로 전달한다.
- **문장·발화 단위 인식이나 녹음 처리:** Qwen. 이번 구성에서 정확도와 처리시간의 조합이 좋았고, SageMaker 엔진 중 6초 분할 오류도 가장 적었다.
- **기존 Whisper 활용:** 영어 전체 문장은 Transcribe와 같은 WER였다. 한국어는 짧은 고정 구간으로 자를 때 오류 증가를 주의해야 한다.
- **Nemotron:** 이번 배치 연결에서는 한국어·영어 모두 오류가 더 많았다. 모델 고유의 지속 스트리밍과 별도로 개발 중인 스트리밍 경로는 이 표의 평가 대상이 아니다. 배치 결과만으로 그 경로의 지연이나 정확도를 판단하지 않는다.

Nemotron은 숫자를 한글·영문 수사로 출력하기도 하므로 점수 일부는 표기 차이다. 다만 영어 샘플 4에서 정답의 `Many people don't think about them`에 해당하는 구간을 `Maybe so measin`으로 인식하는 등 실제 단어 누락·오인식도 있었다. 원문과 인식 결과는 [문장별 결과](paired-results.json)에서 확인할 수 있다.

## 서울 배포와 상시 유지 비용

미국 동부에서 GPU 재고 부족으로 기동·설정 전환이 실패해, 사용자 요청에 따라 서울(`ap-northeast-2`)에 두 엔진을 배포했다. 두 서울 엔진의 GPU 호스트와 모델 복제본은 각각 1개이며 최소·최대 용량도 1이다. 백엔드의 `STT_IDLE_SECONDS=0`은 유휴 상태에서 모델을 내리지 않는 설정이다.

운영 백엔드의 서울 리전 연결과 정상 상태를 확인했다. 이전 미국 동부의 두 배치 엔진은 GPU·복제본 모두 0으로 정리했으며, 엔드포인트와 모델 자체는 보존했다. [최종 운영 검증](final-deployment-verification.json)에 상태를 기록했다.

| 엔진 | 이번 구성 | 과금 단위 | 조회 요금 |
|---|---|---|---:|
| Transcribe | 미국 동부 일반 스트리밍 | 인식한 음성 1시간 | 약 $0.60 |
| Whisper | 미국 동부 `ml.g5.2xlarge` | GPU 호스팅 1시간 | $1.5150 |
| Qwen | 서울 `ml.g6.2xlarge` | GPU 호스팅 1시간 | $1.5026 |
| Nemotron | 서울 `ml.g5.2xlarge` | GPU 호스팅 1시간 | $1.8629 |

상시 유지하는 **Qwen·Nemotron 합계는 시간당 $3.3655**, 월 730시간 기준 **약 $2,456.82**다. 기존 Whisper, 스토리지, 전송, 모니터링, 세금 등은 별도다. 음성 시간과 GPU 호스팅 시간은 다른 과금 단위이며 동시 처리량은 측정하지 않았다. 요금은 AWS Pricing API의 2026-10-28 조회값이다.

## 조건과 검증

- FLEURS 테스트 세트의 연속된 행 0–9를 언어별로 사용했다. 한국어 111.12초·정답 447자, 영어 90.98초·정답 1,007자·211단어다.
- 각 조건 1회, 16 kHz·mono·PCM16의 같은 WAV를 모델별로 전달했다. Qwen은 현재 어댑터의 자동 감지, 나머지는 알려진 언어를 사용했다.
- 대소문자·문장부호 차이를 정규화했지만 숫자·수사, 약어, 방언 철자를 임의로 같은 것으로 바꾸지 않았다. 정확한 CER/WER 규칙은 [SOURCE.md](SOURCE.md)에 있다.
- 모든 샘플의 WAV 해시와 정답 일치를 확인하고, 저장된 CER·중앙 처리시간을 원문 결과에서 다시 계산해 검증했다.
- 실제 회의의 잡음, 겹치는 발화, 한 문장 안의 한영 혼용, 화자 분리, 동시 처리량, 번역 품질은 평가하지 않았다.
- 브라우저 수집, 서버 버퍼 타이머, 앱의 무음·환각 필터, 번역은 측정에서 제외했다.
- 초기 기동 실패와 설정 전환 대기는 인식 시간에서 제외했다. 서로 다른 기동 시도와 설정 변경이 섞였으므로 표준화된 콜드 스타트 수치로 제시하지 않는다.
