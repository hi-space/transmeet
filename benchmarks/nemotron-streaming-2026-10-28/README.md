# Nemotron 연속 인식 측정

측정일: 2026-10-28 UTC. 서울(`ap-northeast-2`)의 실제 SageMaker 엔드포인트에서 동일한 FLEURS 한국어 10개·영어 10개를 실제 재생 속도로 전송했다. **40/40 요청이 성공**했다.

| 언어 | 모델 처리 설정 | 성공 | 오류율 | 첫 부분 자막 중앙값 |
|---|---:|---:|---:|---:|
| 한국어 | 320ms | 10/10 | CER 10.07% | 1.97초 |
| 한국어 | 560ms | 10/10 | CER 8.95% | 2.28초 |
| 영어 | 320ms | 10/10 | WER 9.48% | 1.64초 |
| 영어 | 560ms | 10/10 | WER 7.11% | 1.80초 |

이 표본에서는 560ms가 두 언어 모두 오류율이 낮아 기본값으로 유지했다. 한국어 CER과 영어 WER은 서로 다른 지표다. 첫 부분 자막 시간은 서버 연결 준비가 끝난 뒤의 음성 수집 시작 기준이며, 입력 파일의 앞 무음은 포함한다. 사용자 마이크·브라우저 네트워크·번역 지연은 포함하지 않는다. 연결 준비와 마지막 확정 결과의 시차는 각 JSON에 별도로 남겼다.

브라우저는 160ms 간격으로 음성을 보낸다. 발화 중 원문을 갱신하고, 확정된 문장만 번역·저장한다. 모델은 `nvidia/nemotron-3.5-asr-streaming-0.6b`, JumpStart 아티팩트는 `1.0.2`다.

작은 목소리를 버리던 초기 RMS 필터는 실측에서 발견해 수정했다. 최종 코드는 20개 입력을 바이트 단위로 모두 보존하며, 디지털 무음만 대기 중 생략한다. 중단된 초기 결과는 `baseline-fixed-rms-incomplete/`에 진단용으로 보존했다.

실제 동시 세션, AUTO 한국어·영어 인식, 한 연결에서 35초 무음 뒤 언어가 바뀌는 경우도 확인했다. 기록은 `session-validation.json`에 있다. 숫자 표기 차이도 오류율에 포함되며, 소규모 낭독 음성 결과를 모든 회의 환경의 성능으로 일반화하지 않는다. 자세한 조건과 출처는 `SOURCE.md`를 참고한다.

## 운영 적용

웹 배포와 CloudFront 무효화를 완료하고, 최신 운영 백엔드 이미지를 유지한 채 Nemotron 연결 설정을 적용했다. ECS는 정상 작업 1개·대기 0개, 서울 모델 엔드포인트는 `InService`·GPU 1개다. 운영과 동일한 작업 정의/권한으로 실제 한국어 인식과 영어 번역을 확인했다. 검증은 테스트 미팅을 생성하지 않았으며 임시 S3 음성 파일은 삭제했다. 세부 기록은 `deployment.json`에 있다.

기존 Nemotron 배치 엔드포인트도 GPU 1개로 유지돼 있으므로, 스트리밍용 GPU 1개의 호스팅 비용이 추가된다. 이번 작업에서 만든 미국 리전의 실패한 시험 엔드포인트는 모두 정리했다.
