핵심

  • Jetson Thor가 상위 연산, Jetson Xavier가 VCU — 두 컴퓨터는 RJ45 이더넷으로 연결하고, Jetson Thor는 YOLO 전용 구성으로 전력을 줄여 구동시간 3시간 이상을 목표로 함
  • 상부 카메라와 고정형 LiDAR를 따로 장착 — 기본 뎁스 카메라가 바닥을 향하고 있어서, 카메라·LiDAR를 Jetson Thor에 직접 연결함
  • AWS 서비스는 세 개만 기억 — 데이터 수집·모델 배포는 AWS IoT Greengrass·AWS IoT Core, 영상은 Amazon Kinesis Video Streams. 이번 RL 폴리시 학습에는 Amazon SageMaker AI가 필수가 아님
  • 대용량 영상은 SSD를 직접 옮기는 방법이 가장 빠름 — 이더넷은 느리고 불안정하며, 압축하면 데이터 크기가 10배 이상 줄어듦
  • 교육 아젠다와 워크숍 일정은 지원 팀이 정리 — 현장 투입 전인 8월 말~9월 초까지 세팅을 끝내는 것이 목표이며, 문의는 메일 루프로 받음
