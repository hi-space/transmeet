Vision 60의 상위 연산을 Jetson Thor로 옮긴다

Jetson Xavier는 VCU로 남아 액추에이터 제어와 기본 통신만 맡는다. 퍼셉션·주행 플래닝·매핑·관제는 새로 올리는 Jetson Thor가 맡는다. 저수준 모터 제어 접근과 교육 일정은 아직 정하지 못했다.

정해진 것

  • Jetson Xavier는 VCU — 액추에이터 제어와 기본 통신만 맡는다.
  • Jetson Thor가 상위 연산 — 퍼셉션·플래닝·매핑·관제를 맡고 RJ45 이더넷으로 Jetson Xavier와 잇는다.
  • 센서 배치 — LiDAR는 Jetson Thor에 직결하고, 뎁스 카메라가 바닥을 봐서 상부 카메라를 따로 단다.
  • 오도메트리 — 본체 IMU는 시프트가 생겨 쓰지 않고 LiDAR 내장 IMU를 쓴다.
  • SLAM·가감속 제어는 자체 개발 — FAST-LIO2는 실사용 성능이 부족했다.
  • 클라우드 시작 구성 — AWS IoT Greengrass·AWS IoT Core·Amazon Kinesis Video Streams 세 가지로 간다. RL 정책만 학습하므로 Amazon SageMaker AI는 쓰지 않는다.

  • AWS 팀 — 워크숍 형식·일정·아젠다를 뽑는다 — 기한 미정

  • 담당 미정 — 로봇을 현장에 수동 운용으로 투입한다 — 8월 중순부터 가능
  • 담당 미정 — 현장 영상으로 Amazon Bedrock VLM 후보를 테스트해 고른다 — 기한 미정
  • AWS 팀 — 메일 루프로 문의를 받고 전문가 네 명 중 한 명이 답하며 에셋을 공유한다

이번 지원은 AWS 팀의 고객 지원 프로그램으로 진행한다. AWS 팀은 원래 파트너를 직접 지원하지 않는다.

남은 위험·확인할 것

  • 저수준 모터 제어 — 계단 전환에 필요한 발 모터 제어를 Ghost Robotics가 열어 줄지 아직 모른다. 데이터 개방도 약속보다 제한적이다.
  • 구동시간 — Jetson Thor·상부 카메라·LiDAR를 단 상태로는 아직 재지 않았다. 기존 3시간 이상은 추가 장비가 없을 때 기준이다.
  • 저장 장치 — Jetson Thor 모듈에는 기본 1TB 저장 장치가 없다. SSD를 바꾸려면 그래픽카드를 먼저 떼야 한다.
  • 현장 네트워크 — 실시간 영상·원격 제어는 네트워크가 있어야 한다. 용인 현장의 망 조건은 모른다.추정
  • 교육 일정 — 날짜와 아젠다가 비어 있다. 워크숍이 세팅보다 늦으면 에셋을 다시 만들 수 있다.추정

자세히

AWS 산업안전 데모와 같은 구조로 간다추정

  • 모델 배포 — 클라우드에서 학습한 YOLO를 AWS IoT Greengrass로 Jetson Orin에 배포했다.
  • 영상·메트릭·명령 — 영상은 Amazon Kinesis Video Streams, 메트릭과 원격 명령은 AWS IoT Core(MQTT), 화면은 Grafana.
  • 예외 상황 — YOLO confidence가 낮을 때만 Amazon Bedrock VLM에 보낸다. 바닥의 물처럼 룰 기반 플래너가 못 다루는 상황에 쓸 수 있다.
  • 비용·개발 — IoT 서비스가 가장 싸고 Amazon Bedrock은 토큰 과금이다. 데모 기능은 직접 개발해야 한다.

1시간짜리 360도 영상을 옮기는 방법

  • SSD 직접 교체 — 가장 빠르지만 사람이 기다렸다가 분해해 꺼내야 한다.
  • Wi-Fi 자동 업로드 — 특정 Wi-Fi에 붙으면 올라간다. 경험상 밤새 걸렸다.
  • 도킹 이더넷 — 느리고 불안정해서 거의 쓰지 않는다.
  • 압축 후 업로드 — 장치에서 NVENC로 압축하고 충전 중 올리는 조합이 SSD 교체를 대신할 후보다.추정 10배 이상이라는 압축 효과는 확인하지 못했다.

클라우드 학습과 데이터 저장

  • Isaac Sim 환경 — AWS Marketplace AMI로 바로 띄우고, Amazon EC2 하나를 세팅해 복제한다.
  • 파라미터 제어 — AWS Batch로 환경 ID·로봇·에폭을 한꺼번에 바꾼다. 개별 제어는 SSH·DCV·Slurm.
  • 옮기는 시점 — 클라우드는 로컬보다 느려서 로컬에서 환경·알고리즘을 정한 뒤 확장 단계에 옮긴다.
  • 데이터 레이크 — Amazon S3에 하이브 파티셔닝으로 L0·L1·L2를 두고 Amazon EKS로 처리한다. LiDAR 원시 데이터는 온프레미스가 더 빠르다.

제조사와 현장

  • Ghost Robotics 선택 — 중국산을 빼고 비교했을 때 가장 나았다.
  • 총판 — KRM이 올해 4월 끝나고 LIG Nex1이 넘겨받았다고 한다. 공식 자료로는 LIG Nex1의 지분 60% 인수만 확인된다.
  • 현장 일정 — 용인 현장 실측과 두 차례 방문을 잡고 있다. 울산은 시험장으로 쓰기 어렵다. 시점과 담당은 미정.
  • 현장 방문 빈도 — 시뮬레이션만으로는 튜닝에 한계가 있어 자주 갈수록 좋다.
공식 자료로 확인한 사실
  • Vision 60 사양 — 내장 컴퓨터는 Jetson Xavier, 연속 보행 3시간 이상. 뎁스 카메라 방향은 사양에 없다.
  • Jetson Thor 사양 — 1TB NVMe는 개발자 키트 구성품이고, 모듈은 PCIe로 NVMe를 붙인다. 소비 전력 40–130 W.
  • Amazon Kinesis Video Streams HLS 재생 — 지연은 보통 3–5초이고 지난 영상도 다시 본다.
  • AWS IoT Greengrass 모델 배포 — Jetson 계열 엣지 장치에 모델을 배포할 수 있다.
  • Isaac Sim AMI — AMI는 무료이고 Amazon EC2 비용은 따로 낸다.
  • AWS Batch 다중 노드 강화학습 — Isaac Lab 학습을 여러 노드에 나눠 돌린다.
  • NVIDIA Video Codec SDK — 2026년 1월부터 Jetson Thor 인코딩을 지원한다. 압축률 수치는 없다.
  • LIG Nex1의 Ghost Robotics 인수 — 지분 60% 인수는 확인되고, 국내 총판 이관은 출처에 없다.
