# TransMeet 비교 그림

기존 `compare`와 `matrix` 유형을 유지하는 보완 지침입니다.

- `compare`: 전후 상태나 대안 2–3개를 같은 기준으로 나란히 비교합니다.
  공통 요소는 같은 위치에 두고 바뀐 부분만 강조합니다. 실제 구조가
  달라지면 구조를 직접 그리며, 설명 문장만 든 같은 크기 박스를 반복하지 않습니다.
- `matrix`: 행은 대안/대상, 열은 기준으로 두고 교차 셀에 확인된 값이나
  조건을 적습니다. 실제로 두 연속축이 있는 포지셔닝일 때만 `quadrant`를
  선택하며, 일반 비교표를 임의의 사분면으로 바꾸지 않습니다.
- 값·우열·점수를 지어내지 않습니다. 대안과 기준이 적으면 간단한
  정렬만으로 관계를 보여주고 연결선을 생략합니다.
- 원본 스킬의 여백·초점·겹침 방지 원칙과 현재 페이지의 SVG 규칙을 따릅니다.
