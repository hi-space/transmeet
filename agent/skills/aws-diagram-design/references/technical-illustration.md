# Technical illustrations — 물체와 동작을 설명하는 도해

TransMeet 보완 지침입니다. 원본 AWS 스킬의 27개 유형에 아래 선택지를
추가합니다. **실물의 위치·형태·감지·운동이 설명의 핵심이면 이 유형을
우선 검토합니다.** 모든 주제를 박스와 연결선으로 바꾸지 않습니다.

## 유형 선택

| figure.kind | 설명할 내용 | 그림의 구성 |
|---|---|---|
| `annotated` | 부품의 위치와 역할 | 단순화한 물체 윤곽 + 부품 + 설명선 |
| `coverage` | 시야·감지·도달 영역 | 물체 + 반투명 부채꼴/원호 + 영역 라벨 |
| `cutaway` | 외부에서 보이지 않는 내부 | 일부를 열거나 절개한 외장 + 내부 부품 |
| `exploded` | 부품의 결합·조립 관계 | 같은 축을 따라 떨어진 부품 + 정렬 안내선 |
| `motion` | 이동·회전·관절 동작 | 물체의 자세 + 궤적/회전 화살표 + 전후 위치 |
| `storyboard` | 시간에 따라 바뀌는 상황 | 같은 대상의 2–4개 장면 + 순서 + 짧은 설명 |

한 그림에 주된 유형 하나를 정합니다. `annotated`에 감지 영역 하나,
`motion`에 부품 라벨 한두 개를 보조로 더할 수 있지만, 센서 배치와
복잡한 회피 과정을 한 화면에 모두 밀어 넣지 않습니다.
시스템 간 메시지 순서는 `sequence`, 조건 판단 자체는 `flowchart`를
고릅니다. `storyboard`의 각 장면에는 실제 대상과 환경의 변화가 있어야
하며 단계 이름만 쓴 박스 세 개로 대체하지 않습니다.

## 기획에 포함할 것

`figure.design`에 아래 내용을 구체적으로 적습니다.

1. 대상과 시점: 위에서 본 이동 로봇, 측면의 관절 팔 등.
2. 입력으로 확인된 부품과 상대 위치. 모르는 위치는 모른다고 적습니다.
3. 보여줄 의미: 어느 센서가 어느 영역을 보는지, 무엇이 어떻게 움직이는지.
4. 배치: 물체 중심, 라벨 여백, 보조 영역, 장면의 순서.
5. 사실과 개념 표현의 구분: 개념적 배치/비례 미반영 여부.

## 공통 그리기 규칙

- 몸체는 둥근 사각형·타원·경로, 바퀴는 원이나 짧은 사각형, 센서는 작은
  원/사각형처럼 허용된 SVG 기본 도형을 조합합니다. 알아볼 수 있는
  실루엣이 목적이며 제품 로고나 정밀 CAD 모델을 만들지 않습니다.
- 센서·부품의 실제 지점에서 설명선을 시작합니다. 라벨은 윤곽 밖의
  빈 공간에 두며, 설명선 끝의 작은 점과 동작 화살표를 구분합니다.
- 그리는 순서는 **배경·감지 영역 → 몸체·부품 → 설명선·연결점 → 글자**입니다.
  설명선은 부품에서 라벨까지 전체가 보여야 합니다. 몸체 내부를 통과하는
  설명선을 불투명한 몸체보다 먼저 그려 가리지 않습니다.
- 물체 윤곽과 부품 라벨은 진하게, 보조 윤곽·이전 자세는 연하게 그립니다.
  같은 부품의 모양과 방향 표시는 여러 장면에서도 일관되게 유지합니다.
- 글자를 작게 줄이지 않습니다. 라벨 수를 줄이거나 높이를 늘립니다.

## 유형별 규칙

### annotated

중심 물체 하나와 부품 3–6개 이내. 센서의 위치와 역할을 짧게 붙입니다.
입력에 위치가 없으면 구체적 장착 위치를 확정하지 말고 “개념 배치”로
표시하거나 위치가 알려진 부분만 라벨링합니다.

### coverage

센서 지점에서 감지 영역을 시작합니다. 영역은 낮은 `fill-opacity`로,
가장자리와 방향은 선/원호로 표현하고 물체·라벨을 가리지 않습니다.
각도·거리·360도 감지를 근거 없이 그려 사실처럼 단정하지 않습니다.
수치가 없으면 축척 없는 “감지 범위 개념도”로 표시합니다. 이 유형의
동심원은 차트의 데이터가 아니라 공간적 범위입니다.

### cutaway

외장 일부를 끊거나 옅게 만들어 내부가 보이게 하고, 남은 외장으로
전체 형태를 유지합니다. 확인된 부품만 넣습니다. 단순화한 내부 배치는
“개념 배치”로 표시하고 실제 제품의 단면도처럼 단정하지 않습니다.

### exploded

부품의 상대적 방향을 유지한 채 한 축으로 간격을 벌립니다. 정렬선은
점선, 조립 방향은 필요한 경우에만 화살표를 씁니다. 분해 간격은 치수가
아니므로 길이 표시를 붙이지 않습니다. 입력에 없는 체결 구조를 만들지 않습니다.

### motion

현재 위치와 이전/다음 자세를 구분합니다. 곡선 화살표는 이동 궤적,
회전 원호는 실제 회전 중심에 놓습니다. 시스템 데이터 흐름의 직각
연결선 규칙을 운동 경로에 강제로 적용하지 않습니다. 속도·회전각·시간은
입력에 있을 때만 표기합니다.

### storyboard

감지 → 정지 → 방향 변경 → 이동처럼 입력에 있는 과정을 2–4장면으로
나눕니다. 각 장면에 물체·장애물·변한 상태를 그립니다. 시점과 축척은
유지하고 바뀐 부분을 강조합니다. 휴대폰 폭에서는 위에서 아래로 읽히게
배치하며 순서 번호와 짧은 설명을 붙입니다.
