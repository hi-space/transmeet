# TransMeet 시각 페이지 적용 규칙

이 문서는 원본 `aws-diagram-design`을 TransMeet 페이지 안의 그림에 적용하는
보완 규칙입니다. 원본은 선택적으로 활용할 참고 자료입니다. 원본에
mandatory·non-negotiable·never라고 적힌 레이아웃 규칙도 이 환경에서는
권장 패턴입니다. 필수 조건은 사실 정확성·가독성·페이지 테마·접근성과
이후 단계별 프롬프트의 기술/출력 계약입니다.

## 표현의 자유

- 기존 유형은 가능한 표현의 전체 목록이 아닙니다. 더 좋은 구성이
  있으면 `freeform`으로 새 구성을 설계하거나 여러 표현을 조합합니다.
- 격자·고정 노드 수·특정 도형·직각선·초점 요소 수·단일 유형 제한을
  맞추기 위해 설명력을 희생하지 않습니다.
- 참고 문서의 요소 수와 치수는 출발점입니다. 페이지 최소 글자 크기와
  읽기 순서를 유지하면서 내용에 맞게 배치와 요소 수를 조정합니다.

## 실행 환경

- 도구 없이 한 번의 응답을 생성하는 단계입니다. 파일 읽기, 스킬 호출,
  셸 실행, PNG 내보내기, 글꼴 설치, 브라우저 확인을 요청하지 않습니다.
- 위에 실제로 첨부된 본문과 참조 문서만 사용합니다. 원본 문서의 다른
  파일 링크는 로드되었다는 뜻이 아닙니다.
- 브랜드·유형·출력 형식을 사용자에게 다시 묻지 않습니다. 기획 단계는
  입력 내용과 선택 기준으로 정하고, 그리기 단계는 전달받은 설계를 따릅니다.
- 기획은 지정된 JSON 하나, 그리기는 지정된 인라인 SVG 하나만 출력합니다.
  설명 문장, 코드 펜스, XML 선언, HTML 문서, 파일 경로를 출력하지 않습니다.

## 페이지와의 일관성

- `page_draw`의 화면별 viewBox·최소 글자 크기를 사용합니다. 원본 예제의
  작은 7–12px 글자와 고정 캔버스 치수를 그대로 복사하지 않습니다.
- 페이지 CSS 변수만 사용합니다. 원본의 16진 색상·AWS 브랜드 색은
  의미상 대응하는 `--ink`, `--muted`, `--line`, `--panel`, `--band`,
  `--paper`, `--key`와 상태 변수로 바꿉니다.
- 글꼴은 페이지에서 상속합니다. 원본의 `font-family`, 내장 글꼴,
  `@font-face`를 복사하지 않습니다. 이름과 보조 설명은 같은 글꼴을 쓰고,
  색·굵기로 위계를 표현합니다.
- 상태 색은 정해짐·새로 추가·위험 등 실제 의미가 있을 때만 사용합니다.
  카메라와 LiDAR처럼 부품 종류를 구분하려고 위험/성공 색을 부여하지 않습니다.
- 페이지가 제공하는 상태 범례를 그림 안에 반복하지 않습니다. 측정 차트의
  계열 식별은 각 계열 가까이에 직접 라벨을 붙입니다.

## 도형과 연결선

- 노드 간 연결은 직선·곡선·직각선 중 의미가 명확한 방식을 선택하며,
  겹침과 라벨 가림을 피합니다. 물리적 윤곽·회전·이동 경로·감지 원호는
  의미에 맞는 곡선을 씁니다.
- 원본의 “연결선을 도형보다 먼저 그린다”는 규칙은 논리적 노드 사이의
  연결에 적용합니다. **물체 도해의 부품 설명선과 연결점은 몸체·부품을
  그린 뒤 위에 그립니다.** 특히 몸체 중앙의 센서를 가리키는 선이 외장
  채우기에 가려져 센서까지 이어지지 않는 그림은 잘못된 그림입니다.
- 주석형 도해의 부품 라벨은 필수 정보입니다. 원본의 “편집자 주석 최대
  2개”와 구분하며, 부품 라벨 3–6개를 출발점으로 내용에 맞게 정리합니다.
- 원본 예제의 요소를 채우려고 노드·화살표·수치를 추가하지 않습니다.
  내용이 단순하면 필요한 요소만 남깁니다.
- 원본에 있는 `<pattern>`, `<symbol>`, `<use>`, `<image>`, `<style>`,
  필터·애니메이션·스크립트는 사용하지 않습니다. 허용된 SVG 도형으로
  직접 구성합니다. 점무늬 배경도 넣지 않습니다.
- 이 호출에는 공식 AWS 아이콘 자산이 제공되지 않습니다. 서비스 이름은
  정확한 라벨로 표시하고 일반 도형을 사용합니다. 공식 아이콘처럼 보이는
  로고나 SVG 경로를 기억으로 지어내지 않습니다.

## 내용과 접근성

- 스킬에 나오는 서비스명·수치·예시 시나리오는 회의의 사실이 아닙니다.
  입력의 트랜스크립트와 리서치에서 확인된 내용만 그림에 넣습니다.
- 그림을 보지 않아도 핵심 관계를 이해할 수 있도록 `<title>`과 `<desc>`를
  채웁니다. `role="img"`와 이 두 요소를 가리키는 `aria-labelledby`를
  지정하고, 모든 id에 전달받은 그림별 접두사를 붙입니다.
- SVG 전체를 내기 전에 라벨 겹침, 선과 글자의 충돌, 화면 밖으로 나간
  요소, 글자 크기, 출처 없는 수치, 현재 단계 출력 형식을 자체 점검합니다.
