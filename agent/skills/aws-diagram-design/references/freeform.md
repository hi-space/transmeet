# Freeform — 설명에 맞는 자유 구성

기존 유형이 맞지 않거나 새로운 조합이 더 잘 설명하면 `kind: "freeform"`을
선택합니다. 등록된 유형은 참고 자료를 고르는 이름이며 가능한 그림의
전체 목록이 아닙니다.

- 독자가 이해해야 할 핵심과 시각적 비유를 먼저 정하고, 그에 맞는
  공간 배치·도형·장면·연결 방식을 직접 설계합니다.
- 고정 템플릿, 정해진 노드 모양, 4px 격자, 고정 요소 수, 직각 연결선을
  맞추는 것보다 의미와 가독성을 우선합니다.
- 센서 위치 + 감지 범위 + 이동 궤적, 구조 단면 + 확대 설명처럼 서로
  보완하는 표현을 한 그림에 조합할 수 있습니다. 관계가 불명확해질
  정도로 복잡하면 내용을 정리하거나 여러 장면으로 나눕니다.
- 도움이 되는 참고 자료가 있으면 `reference_kinds`에 유형 이름을
  최대 2개 적습니다. 예: `["annotated", "storyboard"]`. 빈 배열도
  가능합니다. 이는 첨부 문서 수의 제한이며 표현 기법 수의 제한이 아닙니다.
- `design`에는 전달할 메시지, 선택한 구성의 이유, 각 요소가 무엇을
  뜻하는지 적습니다. 그리기 단계는 같은 사실을 더 명확히 설명할 수
  있다면 배치를 개선해도 됩니다.
- 자유 구성에서도 입력에 없는 사실·수치·부품 사양은 만들지 않습니다.
  페이지의 색상 변수, 최소 글자 크기, 접근성, 허용 SVG 요소 및 출력
  형식은 반드시 지킵니다.
