## 이 단계: write (본문 쓰기)

기획(JSON)의 재료로 페이지의 **모든 글**을 씁니다. 그림·레이아웃은 다른 단계가 맡습니다. 글에만 집중합니다. 기획의 사실을 빠뜨리지 않고, 트랜스크립트로 사실을 확인·보충합니다.

### 무엇을 쓰나
페이지의 글은 **논의 흐름만 서술형**이고 나머지는 전부 불릿입니다. 불릿은 하나에 사실 하나, `<b>리드</b> — 개조식 설명` 형태가 기본입니다.

- `about`: 회의 개요에 들어갈 이 회의의 한 줄 소개(명사형, 예: `Vision 60 연산 구조 변경과 AWS 연동 범위 확인`).
- `headline`: **핵심 메시지** 한 문장(`~합니다`). 이 회의가 바꾼 것. 핵심 결론을 `<mark>` 로.
- `tldr`: 핵심 메시지를 받쳐 주는 결론 불릿 3~5개, 중요도 순. 각 `lead`(명사형 짧은 리드) + `text`(개조식 한 줄, 결론 구절에 형광펜 0~1곳). 이것만 읽어도 회의 결과가 잡혀야 합니다.
- `background`: **백그라운드** 불릿 3~5개. 왜 이 회의를 했는지, 지금 상황, 무엇을 얻으려 했는지. `<b>리드</b> — 설명`.
- `discussion`: **주요 논의** 불릿 5~9개. 다룬 주제마다 결론 하나씩, 시간 순. `<b>리드</b> — 설명`.
- `overview_caption`: 개요 그림을 읽는 법 한 문장.
- `points`: 개요 그림의 번호마다 `title`(명사형 짧은 제목) + `bullets`(2~4개, 개조식).
- `decisions`·`opens`: 항목마다 `title`(명사형) + `detail`(이유·조건·영향 **한 문장**). 자세한 설명은 논의 흐름에 있으므로 짧게.
- `actions`: `who`·`what`·`due`(없으면 빈 문자열). `what` 은 명사형.
- `topics`: 기획의 주제마다
  - `title`: 그 주제의 결론을 담은 명사형 제목(`Jetson Thor가 상위 연산 담당`). 질문형 금지.
  - `paras`: 상세 설명 단락 3~5개. 단락마다 `lead`(굵게 보일 짧은 소제목, 명사형 2~8단어) + `text`(2~4문장 서술, `~합니다`·`~입니다`). 배경 → 정한 내용 → 이유·근거 → 남은 조건 순서로 이어지게. 회의에 없던 사람이 이 단락만 읽고 이해할 수 있게 구체적으로(제품명·수치·대안·이유). 문장마다 한 가지 사실, 쉼표로 줄줄이 잇지 않습니다.
  - `caption`: 그림 캡션 한 문장.
- `references`: **리서치 결과**의 출처마다 `title`·`url`·`verdict`(`ok` 일치 / `diff` 다름 / `na` 확인 불가)·`note`(무엇이 맞고 무엇이 다른지 한 문장).
- `implications`: **인사이트**의 시사점 2~4개, 각 `title` + `bullets`(2~3개, 추론은 `추정` 표시).

### 출력 — JSON 하나만 (코드 펜스 없이)
```
{"about": "...", "headline": "...", "tldr": [{"lead": "...", "text": "..."}],
 "background": ["<b>...</b> — ..."], "discussion": ["<b>...</b> — ..."],
 "overview_caption": "...",
 "points": [{"n": 1, "title": "...", "bullets": ["..."]}],
 "decisions": [{"title": "...", "detail": "..."}],
 "actions": [{"who": "...", "what": "...", "due": "..."}],
 "opens": [{"title": "...", "detail": "..."}],
 "topics": [{"id": "t1", "title": "...", "paras": [{"lead": "...", "text": "..."}], "caption": "..."}],
 "references": [{"title": "...", "url": "https://...", "verdict": "ok", "note": "..."}],
 "implications": [{"title": "...", "bullets": ["..."]}]}
```
