## 이 단계: draw (그림 하나 그리기)

그림 설계와 그 그림이 놓일 자리의 본문을 받아 **인라인 SVG 그림 하나**를 그립니다. 글은 다른 단계가 썼습니다. 그림은 본문이 말하는 내용을 한눈에 보여줘야 합니다.

### 그림 원칙
- 박스 나열에서 멈추지 않습니다. 위치(층·좌우·순서), 크기(중요도), 선(흐름·의존), 색(상태)이 **각각 의미**를 갖게 합니다.
- 상태 색: 정해짐 `--ok`/`--ok-bg`, 새로 추가 `--new`/`--new-bg`, 미확인·위험 `--risk`/`--risk-bg` + 점선 테두리(`stroke-dasharray`), 조건부 제안 `--muted` 점선 + `--panel` 배경, 기존 `--line` 테두리 + `--panel` 배경.
- 그 밖의 색: 글자 `--ink`, 보조 글자 `--muted`, 선 `--line`, 영역 배경 `--band`, 페이지 배경 `--paper`, 핵심 강조 `--key`(**배경 채우기에만** — 글자색·선색으로 쓰면 흰 배경에서 읽히지 않습니다). **색은 모두 `fill="var(--…)"`·`stroke="var(--…)"` 로** 씁니다(다크 모드 대응). 16진 색을 직접 쓰지 않습니다.
- 라벨은 용어 표기의 정식 표기, 명사형 개조식. 라벨이 박스 밖으로 넘치지 않게 박스 폭을 글자 수에 맞춥니다(한글 한 글자 ≈ 글자 크기 1배, 영문 ≈ 0.55배). 긴 라벨은 `<tspan>` 두 줄로.
- 선과 화살표가 글자·박스를 가로지르지 않게. 화살표 머리는 `<marker>`.
- **범례를 그림 안에 넣지 않습니다.** 페이지가 상태 색 범례를 따로 보여줍니다.
- 글꼴은 지정하지 않습니다(페이지 글꼴을 따릅니다). `font-weight` 로 위계를 냅니다.

### 크기 (화면에 표시되는 폭 기준)
- **개요 그림 넓은 판**: `viewBox="0 0 1120 H"`(데스크톱 전체 폭), 글자 15px 이상.
- **개요 그림 세로 판**: `viewBox="0 0 400 H"`(휴대폰용). 같은 내용을 위→아래로 다시 배치하고, 요소 설명은 줄여 핵심 이름만. 글자 14px 이상. 번호는 넓은 판과 같은 요소에.
- **주제 그림**: 한 벌, `viewBox="0 0 560 H"`, 글자 17px 이상(휴대폰에서 줄어들어도 읽히게). 요소는 6~10개 이내로.

### 기술 제약 (어기면 거절됩니다)
- `<svg>` 마다 `viewBox`, `role="img"`, 첫 자식으로 `<title>`(그림 내용 한 문장). `width`·`height` 속성과 `style` 속성으로 크기를 고정하지 않습니다.
- 쓸 수 있는 요소: svg g path rect circle ellipse line polyline polygon text tspan title desc defs marker linearGradient stop clipPath. `<style>`·`<script>`·`<use>`·`<image>`·`<foreignObject>`·애니메이션·`on*` 속성 금지. `url()` 은 `url(#id)` 만. id 는 주어진 접두사로 시작(그림끼리 겹치지 않게).

### 출력
SVG 하나만 출력합니다(설명·코드 펜스 없이). 개요 그림 넓은 판은 `<svg class="ov-wide" …>`, 세로 판은 `<svg class="ov-tall" …>`, 주제 그림은 `<svg …>`.
