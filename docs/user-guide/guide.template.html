      어떤 소리를 들을지 정하세요.

      언어를 확인하세요.

      상단을 입력 · English / 번역 · 한국어로 맞춥니다. 한국어와 영어가 섞이면 입력 · 자동 / 번역 · 반대편을 사용할 수 있습니다.

    4. 4
      녹음을 시작하세요.

      대화 영역 아래의 녹음 시작을 누르고 마이크 권한을 허용합니다. 시스템 오디오를 선택했다면 공유할 화면·탭을 고르고 오디오 공유도 켭니다.

    5. 5
      원문과 번역을 확인하세요.

      말하면 대화에 자막이 표시됩니다. 직접 말하기 어렵다면 내 메모에 한국어를 입력해 영어로 번역할 수 있습니다.

    6. 6
      끝나면 회의를 정리하세요.

      회의 종료를 누릅니다. 녹음 중이라면 확인 창에서 종료를 확인한 뒤, 요약과 회의 페이지의 진행 상태를 살펴보세요.
