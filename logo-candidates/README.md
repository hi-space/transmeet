# TransMeet 로고 후보

`00-comparison.png`에서 네 후보를 한눈에 비교하고, `index.html`을 브라우저로 열면 개별 이미지를 크게 볼 수 있습니다.

| 번호 | 후보 | 의미 |
| --- | --- | --- |
| 1 | 대화의 연결 | 서로 다른 두 대화가 하나의 고리로 연결됩니다. |
| 2 | 대화 리본 | 양방향으로 오가는 통역의 흐름을 표현합니다. |
| 3 | 미팅 브리지 | 두 말풍선의 곡선을 연결해 meet의 m을 만듭니다. |
| 4 | 열린 대화 | 서로 맞물린 말풍선이 언어 사이의 연결을 표현합니다. |

- PNG: 흰 배경, 1600 × 640 px.
- SVG: 투명 배경, 벡터 원본. 글꼴 설치 없이 표시됩니다.
- 비교 이미지: 밝은 배경, 어두운 배경, 작은 아이콘 크기를 함께 표시합니다.
- 워드마크: Outfit 620 굵기를 바탕으로 자간을 조정하고 윤곽선으로 변환했습니다. 글꼴 라이선스는 `Outfit-OFL.txt`에 있습니다.
